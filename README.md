Welcome to VintedMaghreb 👗🌍

VintedMaghreb is a full-stack web application created as a Final Year Project (PFE). It’s an online marketplace inspired by Vinted, designed specifically for users in the Maghreb region (Morocco, Algeria, Tunisia) to buy and sell second-hand clothes in a safe and user-friendly environment.

🔧 Technologies Used
💻 Frontend
React.js (with Vite for fast development)

TypeScript

Tailwind CSS – For responsive, modern UI

shadcn/ui – Reusable, accessible UI components

🖥️ Backend

Node.js + Express.js – RESTful API

MySQL – Relational database for storing users, products, and transactions

🚀 Features

👤 User authentication and session management

🛒 Product listing, shopping cart, and favorite system

🧾 Order management with status updates

🧑‍💼 Admin dashboard to manage users and products

🔐 Secure login and data validation

⚙️ Getting Started

To run this project locally, make sure you have Node.js, npm, and MySQL installed.

Backend Setup :

# Step 1: Navigate to the backend folder
cd backend

# Step 2: Install dependencies
npm install

# Step 3: Create a `.env` file and configure database connection
DB_HOST=localhost
DB_USER=your_user
DB_PASSWORD=your_password
DB_NAME=vintedmaghreb_db

# Step 4: Start the Express server
npm run dev


Frontend Setup :

# Step 1: Navigate to the frontend folder
cd frontend

# Step 2: Install dependencies
npm install

# Step 3: Start the development server
npm run dev


📦 Deployment
You can deploy the frontend using platforms like Vercel, Netlify, or GitHub Pages, and the backend on Render, Railway, or your preferred server.

📚 Project Goal
VintedMaghreb aims to:

Promote sustainable fashion and reduce textile waste in the Maghreb.

Empower individuals to give new life to their unused clothes.

Create a trusted online space tailored for the local market.
